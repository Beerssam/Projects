# Battery Dashboard — pi-star mobile hotspot

Sam's first project ever: a self-contained battery/status page for the
WPSD mobile hotspot (UPS HAT E), generated by a bash script reading the
UPS chip over I2C and served by nginx on port 7777. Now also reachable
publicly via https://pi-star.freeddns.org/battery/ (Pi5 proxy + basic
auth).

## Preservation rule

`original/` is the frozen, byte-exact capture of the code as it ran on
2026-11-27. It is NEVER edited. Improvements live in `v2/` (and later
version folders), each deployable on its own. The original was captured
from the live hotspot and verified byte-for-byte against the running
files (md5 manifest below) before being committed.

Excluded, deliberately: `UPS_HAT_E/system_config/rclone.conf` contains a
credential and is never committed. It exists only on the hotspot and in
Sam's own Google Drive backups.
